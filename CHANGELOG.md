# Changelog

All notable changes to **Sea Lion Sounds** are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-17

### Added

- Sea lion typing sounds, driven by `workspace.onDidChangeTextDocument` with a
  configurable leading-edge throttle (`seaLionSounds.typing.cooldownMs`).
  Undo/redo, background edits and large pastes are filtered out.
- Terminal success and failure sounds, driven by the real exit code from
  `window.onDidEndTerminalShellExecution`.
- `seaLionSounds.terminal.unknownExitCode` to choose what happens when the shell
  reports no exit code, such as on `Ctrl+C`.
- Custom `.mp3` and `.wav` support for all three sounds, with validation and a
  fallback to the bundled audio when a configured path is wrong.
- Master volume plus independent typing and terminal volumes.
- Status bar toggle (`🦭 Sea Lions: ON` / `OFF`).
- Eight Command Palette commands, including three that audition the sounds.
- **Sea Lion Sounds** output channel for backend, terminal and playback logging.
- Cross-platform audio: a single persistent PowerShell/MCI worker on Windows,
  `afplay` on macOS, and an `ffplay`/`mpv`/`mpg123`/`paplay`/`aplay` chain on Linux.
- Synthesised placeholder sounds generated by `scripts/generate-sounds.js`.
- A sea lion pet in the bottom panel: it wanders on its own, sleeps when
  clicked, and can be dragged anywhere. Implemented as a webview because
  extensions cannot draw over the editor or the desktop.
- `scripts/trim-typing.js` to cut a long recording down to a keystroke-sized
  bark, and a guard so `npm run sounds` never overwrites real recordings.
- `seaLionSounds.typing.inTerminal` (default off) to bark while typing in the
  integrated terminal, implemented with keybindings because VS Code exposes no
  terminal keystroke API. Letters, digits and space only; see the README.
- Sounds are opened at activation rather than on first use, and a repeated
  keystroke now sends one command instead of two.
- Default `typing.cooldownMs` lowered to 40 ms for a snappier response.
- A four-device voice pool per sound on Windows, so fast typing retriggers
  cleanly. MCI ignores a `play` on a device that is still playing, which
  otherwise dropped every keystroke that landed inside the previous sound.
